1. Открой TaskPlanner.csproj в Visual Studio 2022 (нужна нагрузка ".NET desktop development" и .NET 8 SDK).
2. В pgAdmin в нужной базе выполни database.sql (создаёт 7 таблиц и тестовые данные).
3. Нажми F5. При первом запуске откроется окно "Настройки подключения":
   впиши сервер, порт, имя базы, пользователя и пароль, нажми "Проверить", затем "Сохранить".
   Настройки хранятся в файле connection.txt рядом с программой.

Тестовые пользователи (пароль = "pass" + номер):
  user1  / pass1   - администратор
  user2  / pass2   - менеджер (user2 ... user10)
  user11 / pass11  - пользователь (user11 ... user120)
